# Яндекс Музыка — интеграция без неофициального API

Swipe Music **не является** официальным партнёром Яндекс Музыки.

## Исследование

Публичной документации API Яндекс Музыки для сторонних приложений нет. Существующие клиенты (`MarshalX/yandex-music-api`) явно помечены как неофициальные и используют внутренний `api.music.yandex.net` и client_id официального приложения. Это не разрешённый способ.

Yandex OAuth (oauth.yandex.ru) — общая платформа Яндекса; отдельного публичного scope «Яндекс Музыка для стороннего плеера» в открытой документации нет.

## Режим

**B — ручные HTTPS-ссылки** на `music.yandex.ru` (и соседние зоны `.com/.by/.kz/.uz`).

Не реализуется: OAuth, поиск по каталогу, импорт медиатеки, встроенный Play, копирование токенов из браузера.

## Что умеет пользователь

1. Открыть источник «Яндекс Музыка».
2. Вставить ссылку вида `https://music.yandex.ru/album/…/track/…`.
3. Указать название и исполнителя.
4. Положить запись в каталог рядом с Zaycev.net и демо-треками.
5. Открыть оригинал кнопкой «Открыть в Яндекс Музыка».

## Будущий режим A

Нужны партнёрский доступ и официальная документация. Секрет не кладётся в образ; заготовка: `YANDEX_MUSIC_CLIENT_ID` в `.env`.
