# Интеграция Zaycev.net

Swipe Music **не является** официальным партнёром Zaycev.net.

## Режим

**B — ручные ссылки.** Официального API для сторонних приложений не опубликовано.

Документы сервиса:

- https://zaycev.net/
- https://zaycev.net/spages/about.shtml
- https://zaycev.net/spages/useragreement.shtml
- Лейбл (не developer API): https://label.zaycev.net

Неофициальный `api.zaycev.net/external` **не используется**.

## Что умеет приложение

Пользователь сохраняет HTTPS-ссылку на страницу композиции на `zaycev.net` / `www.zaycev.net` / `ru.zaycev.net`, указывает название и исполнителя, назначает каталог. В медиатеке запись видна вместе с треками других источников. Кнопка открывает оригинальную страницу. Встроенного плеера нет.

## Что не умеет

- Поиск по каталогу Zaycev.net
- Импорт аккаунта / OAuth
- Подтягивание метаданных с сайта
- Скачивание и стриминг аудио
- Кнопка Play
- Заявление «аккаунт подключён»

## Включение режима A

Нужны: письменное разрешение, документация endpoints и секрет в `.env` (`ZAYCEV_PARTNER_KEY`). До этого переменная не читается и ключ не требуется.
