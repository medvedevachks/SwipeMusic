# Яндекс Музыка

Официального API для сторонних приложений нет. Swipe Music сохраняет ссылки на страницы треков и открывает их на music.yandex.ru.

Неофициальный `api.music.yandex.net` и чужие OAuth client_id **не используются**.

Подробности: [архитектура](../architecture/yandex-music-integration.md).
